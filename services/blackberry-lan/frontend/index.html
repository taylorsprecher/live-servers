BlackBerry LAN — Air Platform Core

The runnable core of the BlackBerry 10 / QNX + Python design (BlackBerry_LAN.pdf): the AirCore stack VM, the AirBridge message bus, and the AirShield zero-trust policy, running as a fleet service.

  • GET /blackberry/health — service status
  • GET /blackberry/diagnostics — core diagnostics (cpu / memory / sandbox)
  • GET /blackberry/shield — AirShield policy and AirBridge route table
  • POST /blackberry/aircore/run — run a program, e.g. {"program": ["PUSH 5", "PUSH 3", "ADD", "HALT"]} → stack [8]
  • POST /blackberry/bridge/send — send on a routed channel (diagnostics, echo)
  • GET /blackberry/bridge/messages?channel=echo — read the bus

The handset layers in the design (Cascades/QML UI, C++ bridge, signed .bar packaging for a BlackBerry 10 device) are design material for a device build; this service is the server-side core.
