Stream Mic

The Stream Mic as a Python app for the phone — one tap on Enable and it streams, no Safari in between.

What it does

Stream Mic records this phone’s microphone in 10-second chunks and sends each chunk to the receiver on the member server — the same open-access upload the web page uses. Enable starts a session; Stop ends it. Ask Jasmine for a session’s audio or a transcript.

Built as an app because of the Safari pop-out: on the web page, iOS puts its own screen-sharing card in the flow. In the app there is no browser step at all — the only prompt is iOS’s microphone permission, asked once.

Python core tested 8/8Receiver already on the server

The iPhone app project

A BeeWare Briefcase project (Toga), same shape as SSK Python: the streaming loop and the uploader are pure Python and unit-tested; the microphone bridge uses AVFoundation on iOS. Download the project and build it on the Mac — the signed iOS build and TestFlight are Mac-side steps, like SSK Python’s.

Download the Briefcase project (.zip)
  1. On the Mac: briefcase create iOS
  2. briefcase build iOS
  3. briefcase run iOS, or open the Xcode project to sign and install with Taylor’s Apple account.
