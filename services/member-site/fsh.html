Eigenvector centrality is based on a simple idea:

A node is important if it is connected to other important nodes.

Unlike degree centrality, which just counts connections, eigenvector centrality recursively weights connections by the importance of the neighbors.

Mathematical Definition

Suppose a network has an adjacency matrix (A), where:

[ A_{ij} = \begin{cases} 1 & \text{if node } i \text{ is connected to node } j \ 0 & \text{otherwise} \end{cases} ]

Let (x_i) be the centrality score of node (i).

Eigenvector centrality defines:

[ x_i = \frac{1}{\lambda}\sum_j A_{ij}x_j ]

In words:

The centrality of node (i) equals the sum of the centralities of its neighbors.

(\lambda) is a scaling constant.

In matrix form:

[ Ax = \lambda x ]

This is the classic eigenvalue equation.

The eigenvector centrality scores are the components of the eigenvector associated with the largest eigenvalue of the adjacency matrix.

Iterative Computation

In practice, eigenvector centrality is usually computed using the power iteration method:

Assign every node an initial score (often 1).

[ PR(i)

\frac{1-d}{N} + d \sum_{j \in M(i)} \frac{PR(j)}{L(j)} ]

(N) = total number of pages

(d) = damping factor

(M(i)) = pages linking to (i)

(L(j)) = outgoing links from page (j)

The first term represents random jumps.

The second term distributes importance through links.

Suppose we have three pages:

[ P= \begin{bmatrix} 0 & 0 & 1 \ 1/2 & 0 & 0 \ 1/2 & 1 & 0 \end{bmatrix} ]

[ G = dP + (1-d)\frac{1}{N}E ]

(d) = damping factor (typically 0.85)
