SSK Python

Find the SSK portable cloud drive from the iPhone. No computer — the phone does the hunting and the cable test.

What it does

SSK Python sweeps the Wi-Fi network the phone is on for the drive’s services — its web UI (port 80, identified by its SSK markers), its FTP banner (21) and SMB file sharing (445) — and gives a plain verdict: found, or not on this network. The same screen carries the USB-C disk-alive steps below.

Latest server-side hunt (Nov 22, 2026): the drive answered at no known address on the home network, and the SSKCloud app already holds every phone permission it needs — the drive itself is the silent side. The cable test is the deciding step.

The iPhone app project

The app is packaged with BeeWare Briefcase (Toga interface, bundle net.911transedu.sskpython) following the Python iOS Deployment Checklist. Phases 1–3 are complete — environment, project, dependencies, and the Local Network permission wording the scan needs. Phases 4–12 (create the iOS project, run on simulator and iPhone, Xcode signing, TestFlight) run on the Mac with the owner’s Apple Developer account.

Disk-alive test — USB-C, no computer

  1. Plug the SSK drive into the iPhone with a USB-C cable.
  2. Open Files > Browse and look under Locations.
  3. If the drive appears, the disk is alive and its files are right there.
  4. If nothing appears, note whether the drive’s light came on or it spun up — that says which way it failed.

The iPad route also works with Apple’s Lightning to USB 3 Camera Adapter — the version with the power pass-through port, with a charger plugged in, because a portable drive draws more than the iPad alone supplies over Lightning.
