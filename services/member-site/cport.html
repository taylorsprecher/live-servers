C-Port Python

The C-Port serial protocol as an installable Python package — a CPython C extension for the framing and CRC work, with the ingestion pipeline on top.

What it is

The package (cport-python 1.0.0) comes from the C-Port Python specification in Taylor’s C-Port_Python document — the same document that pairs it with the USB-C to Lightning power and protocol specifications.

  • cserialproto — a C extension that validates each 14-byte frame (sync marker 0xAA55, big-endian >HHffH) and verifies its CRC16-CCITT checksum (poly 0x1021, init 0xFFFF, over the first 12 bytes) before returning the reading as a dict.
  • cport_python.pipeline — the sync-hunter serial reader, dual-write logging (append-only text stream + SQLite), and SAS XPORT (.xpt) export on shutdown.

Verification — Nov 22, 2026

Built with gcc on Python 3.12 and installed before it was listed here. The C CRC16 matches an independent reference implementation on every test buffer; valid frames parse to the exact packed values; bad-CRC, wrong-sync, and wrong-length frames are all dropped; the pipeline’s text log, SQLite log, and XPORT export all write and read back. One design note: the serial reader sheds one noise byte per attempt and lets the pipeline loop walk to the sync marker — as the specification wrote it.

The package

Source layout follows the specification’s module distribution: pyproject.toml, setup.py, cserialproto.c, and the cport_python package. Build and install:

  • python setup.py build_ext --inplace
  • pip install .
